# FAQ
### <i>"What is this?"</i>
### UncBuild is just Ishiiruka FPM 3.1.2, but given some themeing and some pre-configured tags for various netplayers out there!

### <i>"Can I netplay vs someone on the new P+ Dolphin?"</i>
### No, in order to netplay you and your friend must both be playing on the same Dolphin revision. You can check which revision your own by going to Help > About in Dolphin and looking at the revision number.

### <i>"Can I play a build that's not vanilla? Like Illinois or SG?"</i>
### Yes! All you'll have to do is select the `sd.raw` file for the build you want to play on. Switch this by going to Config -> Paths -> SD Card Path -> ... -> <i>select the sd.raw</i>
